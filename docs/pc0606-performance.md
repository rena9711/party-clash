# PC-06-06｜多人效能與回歸驗收報告

基準為 PR #6 上 PC-06-05 第二版已驗收模型，commit `6999a9186478c918b971c77b14980d68ac4ccafe`。全部數據來自本機 Chromium SwiftShader 軟件渲染或本機 Socket.IO 測試。**未完成真機驗證。**

## 方法

同一執行環境，畫面 393 × 760 CSS px，DPR 0.65。多人使用相同種子賽道及同一組角色。瀏覽器渲染一位參賽者，其餘使用真實 Socket.IO 客戶端。單組量測約 4 秒，平均 FPS 以 rAF 計算。1% Low 定義為最慢 1% 幀間隔嘅平均值取倒數，短樣本會受單一長幀影響。

Draw Calls 採每幀中位數。記憶體量度瀏覽器 JS heap 同本機伺服器 RSS，未包含 GPU 使用量。快照大小為每次 Socket.IO `race-state` 事件加 Engine.IO 前綴嘅 UTF-8 平均位元組。延遲表列快照從伺服器標籤到測試橋交付視圖嘅 P50／P95；Socket.IO ACK 測試從同一瀏覽器到本機伺服器，未經人工延遲橋。弱網組模擬單程 135ms、額外 0–100ms 抖動，每四個快照丟一個。單人遊戲無網絡同步。

## 負載同改動

- 城市每幀原本重算同上傳 216 個實例矩陣。依家只喺跨越 12 單位路段時更新，段內用同一父節點平移。四種霓虹燈顏色合併到一個實例批次，每幀少三次 Draw Calls。
- 跑手動畫用嘅代理節點移出渲染樹，只更新可見動畫子樹。保留原有模型幾何、配色、配件同遠距 LOD，碰撞與伺服器模擬保持原規則。
- 保留快照協議、插值、預測同伺服器更新頻率。局內快照大小只隨當刻座標等資料變動。弱網測試使用瀏覽器橋注入缺包，並無量測真實流動網絡。
- FPS 同長幀結果有升有跌。數據確認減少渲染提交同街景矩陣更新，可以繼續用真機確認 GPU 表現。此報告未驗證手機 30 FPS。

## 回歸

- 7 組固定 WebGL 畫面涵蓋單人預覽、10 人近景、跨路段與 LOD 切換。合計 2,090,760 個像素中有 223 個不同，其中 221 個最多相差一個 RGB 階，兩個較大差異出現在跨路段時。已驗收模型幾何和材質資料保持原樣。

- 18 項單元測試及 7 項 Socket.IO 回歸。覆蓋 2、5、10 人開始及結算、不重複角色、全員確認、暱稱、重連、碰撞扣血、無敵期、跳躍、星星、加速及伺服器權威計分與排名。
- 5 組瀏覽器感應器模擬涵蓋授權、拒絕、無讀數、無感應器、橫直屏、自動及手動校準、觸控後備。實際 iPhone Safari／Android Chrome 仍待驗證。
- 弱網短測保留本地預測同遠端插值。完整 45 秒結算回歸喺本機正常連線下完成。
